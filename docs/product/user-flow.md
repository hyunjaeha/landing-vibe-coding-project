# 방문자/운영자 흐름

기준 문서: `docs/product/mvp-scope.md`

## 문서 역할

이 문서는 PRD를 기준으로 방문자 흐름, 운영자 흐름, 예외 흐름, 화면에 필요한 상태를 정리합니다.

- 이 문서에 쓰는 내용: 5단계 이하의 방문자/운영자 흐름, 예외 흐름, 화면 상태
- 이 문서에 쓰지 않는 내용: 기능 요구사항 표, 랜딩 디자인 토큰, DB 스키마, 운영 절차 상세

관련 상세 문서:

- 제품 범위와 PRD: `docs/product/mvp-scope.md`
- 랜딩 디자인 기준: `docs/design/landing-page-brief.md`
- 운영 기준: `docs/operations/operating-guide.md`

## 방문자 흐름

| 단계 | 화면 | 사용자 행동 | 필요한 화면 상태 |
| --- | --- | --- | --- |
| 1 | 랜딩 첫 화면 | 공유받은 URL로 접속해 워크숍명, 한 줄 소개, 대상자, 장소, 가격을 확인합니다. | 페이지 로딩 중, 정상 표시 |
| 2 | 일정 안내 영역 | 가능한 워크숍 일정과 신청 가능 상태를 확인합니다. | 일정 있음, 일정 없음, 마감 일정 |
| 3 | 문의 폼 | 이름, 전화번호, 희망 일정을 입력하고, 필요하면 문의 내용을 입력한 뒤 개인정보 수집 동의에 체크합니다. | 기본 입력 상태, 필수값 누락, 개인정보 동의 누락, 기본 안내 문구 표시, 수집 목적/보관 기간/삭제 요청 안내 표시 |
| 4 | 문의 제출 결과 | 문의를 제출하고 결과 메시지를 확인합니다. | 제출 중, 제출 성공, 제출 실패 |
| 5 | 접수 완료 화면 또는 메시지 | 접수 완료 안내를 보고 운영자의 개별 연락을 기다립니다. | 접수 완료, 재문의 가능 안내 |

## 운영자 흐름

| 단계 | 화면 | 운영자 행동 | 필요한 화면 상태 |
| --- | --- | --- | --- |
| 1 | 관리자 접근 화면 | 접근 키 또는 단일 관리자 비밀번호로 관리자 화면에 접근합니다. | 접근 입력 대기, 접근 성공, 접근 실패 |
| 2 | 문의 목록 화면 | Supabase에 저장된 문의 목록을 확인합니다. | 목록 로딩 중, 문의 있음, 문의 없음, 로딩 실패 |
| 3 | 문의 목록 내 상세 정보 | 목록 안에서 이름, 전화번호, 희망 일정, 문의 내용, 접수 시간을 확인합니다. | 상세 정보 표시, 문의 내용 없음 |
| 4 | 운영 체크리스트 영역 | 장소 예약, 준비물, 참여자 연락, 사전 안내 메시지, 당일 진행 순서를 확인합니다. | 정적 체크리스트 표시, 체크 상태 저장 없음 |
| 5 | 관리자 문의 목록 화면 | 확인한 전화번호를 기준으로 수동 연락 대상을 정리합니다. | 수동 연락 대상 확인, 시스템 내 자동 발송 없음 |

## 방문자 예외 흐름

| 예외 상황 | 발생 화면 | 화면 상태 | 처리 방식 |
| --- | --- | --- | --- |
| 랜딩 페이지를 불러오지 못함 | 랜딩 첫 화면 | 로딩 실패 | 새로고침 또는 잠시 후 재접속 안내를 표시합니다. |
| 등록된 일정이 없음 | 일정 안내 영역 | 일정 없음 | 운영자가 일정을 준비 중이라는 안내를 표시하고 문의 폼은 사용할 수 있게 둡니다. |
| 일정이 마감됨 | 일정 안내 영역 | 마감 일정 | 마감 상태를 표시하고, 문의는 가능하지만 예약 확정이 아니라는 안내를 표시합니다. |
| 필수 입력값을 입력하지 않음 | 문의 폼 | 필수값 누락 | 이름, 전화번호, 희망 일정 중 누락된 항목 근처에 안내 문구를 표시하고 제출을 막습니다. |
| 개인정보 수집 동의를 체크하지 않음 | 문의 폼 | 개인정보 동의 누락 | 동의가 필요하다는 안내를 표시하고 제출을 막습니다. |
| 문의 제출에 실패함 | 문의 제출 결과 | 제출 실패 | 입력값은 유지하고 잠시 후 다시 시도하라는 안내를 표시합니다. |

## 운영자 예외 흐름

| 예외 상황 | 발생 화면 | 화면 상태 | 처리 방식 |
| --- | --- | --- | --- |
| 접근 키 또는 비밀번호가 없음 | 관리자 접근 화면 | 접근 실패 | 문의 목록을 표시하지 않고 접근 권한이 없다는 안내를 표시합니다. |
| 접근 키 또는 비밀번호가 올바르지 않음 | 관리자 접근 화면 | 접근 실패 | 관리자 화면 진입을 막고 다시 입력할 수 있게 합니다. |
| Supabase 문의 목록을 불러오지 못함 | 문의 목록 화면 | 로딩 실패 | 문의 목록을 표시하지 않고 다시 시도 안내를 표시합니다. |
| 접수된 문의가 없음 | 문의 목록 화면 | 문의 없음 | 빈 목록 대신 아직 접수된 문의가 없다는 문구를 표시합니다. |
| 문의 내용이 비어 있음 | 문의 목록 내 상세 정보 | 문의 내용 없음 | 이름, 전화번호, 희망 일정, 접수 시간은 표시하고 문의 내용은 없음으로 표시합니다. |

## 범위 메모

- 방문자 흐름에는 결제, 회원가입, 예약 확정이 포함되지 않습니다.
- 운영자 흐름에는 검색, 통계, 권한 관리, 상태 변경이 포함되지 않습니다.
- 운영 체크리스트는 정적 표시만 제공하며 체크 상태 저장은 하지 않습니다.
- 운영자가 체크 상태 저장을 기대하는 경우에도 저장, 항목 수정, 사용자별 체크리스트 관리는 제공하지 않습니다.
